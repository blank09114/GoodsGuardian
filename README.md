# 굿즈를 지켜라

---

## 프로젝트 개요

고양이들이 선반에서 굿즈를 떨어뜨리는 상황에서, 플레이어가 캐릭터 ‘프릴’을 좌우로 움직여 굿즈를 받아내는 2D 팬 게임입니다.

시간이 지날수록 굿즈의 생성 간격이 짧아지고 낙하가 빨라지도록 구성했습니다. 굿즈를 놓치면 멘탈이 감소하며, 모두 소진되면 결과 화면에서 해당 플레이의 생존 시간을 표시합니다.

- 개발 형태: Unity 기반 Windows 게임
- 장르: 2D 캐주얼 아케이드
- 개발 인원: 1인 — 개인 프로젝트
- 플랫폼: Windows

## 구조 및 설계

### 역할별 컴포넌트 구성

플레이어와 고양이의 이동, 굿즈 생성, 충돌 처리, 게임 상태와 사운드를 각각의 컴포넌트로 분리했습니다.

`PlayerController`와 `CatController`는 이동을, `DropManager`는 굿즈 생성과 난이도 변화를 담당하도록 구성했습니다. 개별 굿즈는 `GoodsController`에서 충돌 대상을 확인하고, 놓친 굿즈의 피해량을 `GameManager`에 전달하도록 구현했습니다.

굿즈 종류는 `GoodsType` Enum으로 구분하고, 세 종류의 프리팹을 생성 목록에 연결했습니다.

### 씬 구성과 상태 전달

게임은 `MainScene`, `PlayScene`, `ResultScene`으로 구성했습니다. 메인에서 게임을 시작하고, 멘탈이 소진되면 결과 화면으로 이동하며, 결과 화면에서는 다시하기와 메인 복귀를 제공했습니다.

`GameManager`는 플레이 씬에서 멘탈과 시간을 관리하고, 게임 종료 시 생존 시간을 정적 필드로 전달했습니다. 결과 화면의 `UIManager`는 이 값을 읽어 표시하도록 구성했습니다.

`SoundManager`는 중복 객체를 제거하고 `DontDestroyOnLoad`로 유지해 씬 이동 이후에도 음악 재생을 관리하도록 구현했습니다.

## 주요 기능

- 플레이어 조작: 좌우 이동과 이동 방향에 따른 캐릭터 반전
- 고양이 이동: 주기적인 무작위 방향 선택과 충돌 시 방향 반전
- 굿즈 생성: 지정 영역의 무작위 위치에 세 종류의 굿즈 생성
- 난이도 변화: 생성 간격 감소와 새 굿즈의 중력 배율 증가
- 멘탈 관리: 놓친 굿즈 종류에 따른 피해와 게임 오버
- 결과 화면: 생존 시간 표시, 다시하기, 메인 복귀
- 사운드: 메인·플레이·결과 씬에 따른 BGM 전환

## 구현

### 플레이어와 고양이 이동

플레이어는 `Input.GetAxisRaw("Horizontal")`로 좌우 입력을 받고, `FixedUpdate`에서 `Rigidbody2D.MovePosition`으로 이동하도록 구현했습니다. 중력과 회전을 제한하고, 이동 방향에 따라 `localScale.x`의 부호를 변경해 캐릭터가 바라보는 방향을 전환했습니다.

고양이도 같은 물리 이동 방식을 사용했습니다. 일정 시간마다 좌우 중 하나를 무작위로 선택하고, 충돌이 발생하면 진행 방향을 반전하도록 구성했습니다.

### 굿즈 생성과 난이도 변화

`DropManager`에서 지정한 가로 범위 안의 위치를 무작위로 선택하고, `Instantiate`로 굿즈를 생성했습니다. 생성 위치는 고양이의 실제 좌표와 독립적으로 결정하도록 구현했습니다.

일반 굿즈를 기본 생성 대상으로 두고, 시간 조건에 따라 스카디와 한정판 스카디 굿즈를 선택 목록에 추가했습니다. 생성 가능한 종류 중 하나를 무작위로 선택하도록 구성했습니다.

난이도는 플레이 씬의 타이머를 기준으로 20초마다 변경했습니다. 생성 간격은 2초에서 0.2초씩 줄이되 최소 1초로 제한하고, 새로 생성하는 굿즈의 중력 배율은 0.5에서 0.2씩 높이되 최대 1.5로 제한했습니다.

### 충돌 판정과 멘탈 관리

굿즈는 `Rigidbody2D`와 `Collider2D`를 사용하고, `OnCollisionEnter2D`에서 충돌한 오브젝트의 레이어를 확인하도록 구현했습니다.

플레이어와 접촉하면 굿즈를 제거하고, 바닥과 접촉하면 종류에 따른 멘탈 피해를 적용한 뒤 제거했습니다.

| 굿즈 종류 | 멘탈 감소량 |
|-----------|-------------|
| 일반 굿즈 | 1칸 |
| 스카디 굿즈 | 2칸 |
| 한정판 스카디 굿즈 | 3칸 |

초기 멘탈은 5칸으로 설정했습니다. 피해를 적용한 값은 0부터 최댓값 사이로 제한하고, 남은 멘탈에 맞춰 Image 배열의 표시 상태를 변경했습니다. 멘탈이 0이 되면 생존 시간을 전달하고 결과 씬으로 이동하도록 구현했습니다.

물리 레이어는 고양이·굿즈·바닥·플레이어로 구분했습니다. 고양이와 굿즈, 굿즈끼리의 충돌은 충돌 행렬에서 제외했습니다.

### 생존 시간과 결과 표시

생존 시간은 매 프레임 `Time.deltaTime`으로 누적하고, 타이머 텍스트만 약 0.1초 간격으로 갱신하도록 구성했습니다.

게임이 종료되면 누적 시간을 `GameManager.finalTime`에 전달했습니다. 결과 화면에서는 해당 값을 소수 첫째 자리까지 표시하도록 구현했습니다.

### 씬 전환과 BGM

시작·다시하기·메인 복귀 버튼을 `SceneController`의 함수에 연결하고, `SceneManager`로 씬을 전환했습니다.

`SoundManager`는 현재 씬의 음악을 재생하고, `SceneManager.sceneLoaded` 이벤트를 구독해 씬 변경을 감지하도록 구성했습니다. 씬 이름에 따라 인트로·플레이·결과 AudioClip을 선택하고 반복 재생했습니다.

## 기술적 고민 및 개선점

### 라운드 경과시간의 기준 통일

난이도 변화는 플레이 씬 내부의 타이머를 사용하지만, 추가 굿즈의 등장 조건은 전체 실행 경과시간인 `Time.time`을 사용하고 있습니다. 따라서 메인 화면에서 기다린 시간이나 이전 플레이의 영향으로 재도전 시 굿즈가 등장하는 시점이 달라질 수 있습니다.

후속 개선에서는 굿즈 종류 추가와 난이도 변화가 동일한 라운드 경과시간을 참조하도록 정리하고자 합니다. 게임 시작 시 기준 시간을 초기화해 매 플레이에서 같은 시간 조건을 적용할 수 있도록 보완할 필요가 있습니다.

## 설치 및 실행

1. [다운로드 폴더](https://drive.google.com/drive/folders/1Zb8_Xu9UgcZrw5GPNPAsrp-qyvis6v3A)에서 `굿즈를 지켜라!.zip`을 다운로드합니다.
2. 압축 파일 전체를 해제합니다.
3. `GoodsGuardian.exe`를 실행합니다.

실행 파일과 `GoodsGuardian_Data`, DLL 등 동봉된 파일은 함께 유지해야 합니다.

플레이어는 키보드의 `←`, `→` 키로 조작합니다.
